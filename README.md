# The Sanctum 🦇

A personal CRM and second brain — one dark place to track work, life, people, habits, and goals.

At its center sits the oath it's built around:

> **बलिदान परम धर्म**
> *Balidan Parmo Dharma — Sacrifice is the highest duty.*

## What's inside

- **Missions** — work and life tasks, with filters and a done archive
- **People** — your allies, with "days since last touch" so no relationship goes cold
- **The Vault** — notes and quick capture for thoughts before they escape
- **Protocol** — daily habit tracker with a 7-day grid and streak counts
- **Objectives** — long-game goals with click-to-set progress bars
- **Night Watch** — a live clock that knows when Gotham's hours begin (9 PM–5 AM)

## Running it

It's a single `index.html` — no build, no dependencies.

- Open `index.html` directly in a browser, **or**
- Enable GitHub Pages on this repo (Settings → Pages → deploy from `main`) and it's live on the web.

## Your data

Everything is saved in your browser's localStorage — private to your machine.
Use **Export vault** (footer) for a JSON backup, and **Import vault** to restore it anywhere.
